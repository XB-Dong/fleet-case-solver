## 发现并修复的问题

1. Windows 临时查询库文件被连接占用：连接上下文结束时显式关闭。
2. 大数据量写入期间，同步任务另开连接导致 SQLite 锁冲突：批次内部复用同一连接，同时使用 WAL；增加默认规模回归。
3. 小屏侧栏文字隐藏后按钮缺少可访问名称：补充 aria-label 和 title。
4. Doris 镜像名称需要官方确认：固定为官方公开文档列出的 all-slim 实验镜像，并注明容器未验证。
